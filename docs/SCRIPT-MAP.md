# Scripts

Run from repository root. Export `DATABASE_URL` for migration and integration tests; export Auth.js environment for server/build. `npm ci` installs locked dependencies; `npm run dev` starts development; `npm run build` produces a production build; `npm start` serves it. `npm run db:migrate` applies committed migrations; `npm run db:validate` checks Drizzle migration history. Generate future migrations with `npx drizzle-kit generate` after schema changes, review SQL before release. `npm run admin:create` inserts a new admin and audit event. `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e` verify the slice. Tests require an isolated migrated database, running app and browser; E2E writes records. None of these commands resets or deletes an existing database.
