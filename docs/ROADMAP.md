# Roadmap

- Phase 0: repository and local environment audit completed; requirements confirmation, product-owner decisions, policies and VPS review remain open. See [Phase 0 audit](PHASE-0-AUDIT.md).
- Phase 1 core: public landing, family navigation, catalogue, enquiry, credential identity, role enforcement and basic admin, including program lifecycle and enquiry status.
- Phase 2 core: persisted enrolment, learner portal, admin-authored plain-text lessons and completion tracking. Real curriculum, rich media, live sessions, assignments, admissions and payments are not implemented.
- Phase 3: instructor/mentor workflows, assessments and credentials.
- Phase 4: career, employer and enterprise workflows.
- Phase 5: AI assistant, analytics and marketplace.
- Phase 6: scale, localization and mobile.

Before release, complete the security/privacy and operational gaps in SECURITY.md, owner review, production infrastructure validation and full accessibility/manual testing. Role names and area links do not constitute completed products.

The living [master checklist](MASTER-CHECKLIST.md) tracks priorities, evidence, owners, dependencies and production launch gates across all phases.
